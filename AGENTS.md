## Stack

- Next.js 16.4.3, App Router, React 19, TypeScript strict (`noEmit`), Tailwind CSS v4.
- Dev runs on Turbopack; Tailwind via `@tailwindcss/turbopack` rule in `next.config.ts`; design tokens in `src/app/globals.css`.
- React Compiler enabled (`reactCompiler: true` in `next.config.ts`; `babel-plugin-react-compiler` dev dependency) — memoization is mostly automatic; avoid adding redundant `useMemo`/`useCallback`.
- shadcn/ui (base-nova, RSC): `@/components`, `@/components/ui`, `@/lib/utils`, `@/hooks`, `@/lib` (see `components.json` aliases).
- Path aliases: `@/*` → `./src/*` and `@src/*` → `./src/*` (`tsconfig.json` `paths`).

## Commands

- `npm run dev` — Turbopack dev server at http://localhost:3000.
- `npm run build` — `next build`; type-checks and fails on type errors.
- `npm run start` — production server; run `build` first.
- `npm run lint` — ESLint (`eslint-config-next`: web vitals + TypeScript rules).
- `npx tsc --noEmit` — standalone typecheck (no npm script defined).
- No test runner is configured; there is no `npm test`.

## App structure

- `src/app/layout.tsx` — root layout, metadata, `Navbar` + `Footer` from `@/components/home`, Geist fonts via `next/font/google`.
- `src/app/page.tsx` — home page (Hero, Featured, HowItWorks, TrustSafety).
- `src/app/studios/page.tsx` — studio listing (`"use client"`); GETs `http://localhost:5000/studios`.
- `src/app/add-studio/page.tsx` — studio creation form (`"use client"`); POSTs `http://localhost:5000/add-studio`.
- Single app route; no middleware or API routes in this repo.

## Conventions & gotchas

- Backend dependency: both client pages call `http://localhost:5000` (`/studios`, `/add-studio`). That StudioSpace API is NOT in this repo and must be running separately, or studio pages will error / show empty results.
- Server components by default; add `"use client"` only when needed (see `studios` and `add-studio` pages).
- Use `cn(...)` from `@/lib/utils` (re-exports the `cn` package) for className merging; don't add a second utility.
- Prefer `<Image>` from `next/image` over ``; `eslint-config-next` flags `` via `@next/next/no-img-element` (see existing `eslint-disable` in `studios/page.tsx`).
- Import shared types from `@src/lib/type/type.ts` — note the `.ts` extension in the import (e.g. `import type { TStudio } from "@src/lib/type/type.ts"`).
- Brand design tokens live in `src/app/globals.css` (`--color-brand-bronze`, `--color-brand-charcoal`, `--color-brand-ivory`, `--color-brand-stone`, `--color-brand-border`); `tailwind.config` is empty, so styling is CSS variables + arbitrary Tailwind values.
- Icons: `lucide-react`. `next.config.ts` allows remote images from any `https:` hostname.
